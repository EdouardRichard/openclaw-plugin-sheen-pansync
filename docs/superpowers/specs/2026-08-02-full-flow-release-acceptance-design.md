## 执行架构

验收分为四层，上一层通过后才进入下一层：

1. **仓库基线**：运行类型检查、全部单元和集成测试、构建、打包内容与敏感信息泄漏检查。
2. **隔离制品**：在独立 worktree 中构建实际 `.tgz`，安装到独立 OpenClaw 状态目录，验证插件、CLI、Skill、Tool、状态页与配置页面。
3. **当前实例**：把同一 `.tgz` 安装到当前运行实例，重启网关，验证真实运行时注册、权限、状态和重启恢复。
4. **真实账号**：用户完成扫码和 Token 粘贴后，验证真实配置、上传、对话触发、持久化恢复与脱敏。

每个缺陷必须遵循同一流程：稳定复现、收集证据、定位根因、编写并观察回归测试正确失败、实施单一最小修复、运行聚焦测试、运行完整门禁、重新验证原始症状。不能把模拟测试、当前实例 smoke 或真实账号验收互相替代。

## 状态保护与安全边界

- 使用隔离 worktree 保护当前 `main` 的未跟踪内容与现有状态。
- 安装到当前实例前，只记录插件清单、网关状态及相关配置文件的存在性；本机备份不得展示凭证内容，也不得加入 Git。
- 测试对象必须是从确定 checkout 构建的明确 `.tgz`，不能用工作区源码入口替代最终制品。
- 网关重启按“记录状态、停止确认、启动、健康探测、注册检查”执行。失败时停止真实账号步骤并优先恢复网关健康。
- 配置服务只能监听 loopback。完整一次性 URL、动态端口、Token、完整配置 URL 和原始敏感日志不得写入报告或 Git。
- 真实远端文件统一使用本轮唯一前缀，不覆盖已有文件。上传结果不确定时不得盲目重试。
- 不绕过登录、验证码、风控或浏览器安全策略。

## 外部失败验证策略

### 限流

不得对真实 OpenList 或阿里云服务制造限流。只运行由本机假服务返回 `429` 的确定性自动化测试，验证错误映射、`Retry-After` 解析、冷却持久化与冷却期内不重试。

### 网络失败

在隔离 OpenClaw 状态中使用虚构 Token，并把刷新地址指向本机确定性假服务。分别模拟连接失败、请求超时与 `5xx`，验证状态进入 `degraded`、停止立即重试以及重启后继续遵守持久化冷却期。真实 Token 不得进入假服务。

### 未授权与授权被拒绝

- 当前实例安装后、配置前验证 `unconfigured` 与 `CREDENTIALS_REQUIRED` 安全指引。
- `reauth_required` 表示已经保存的 Refresh Token 被上游拒绝，不能用“尚未授权”代替。该分支只在隔离状态中使用虚构 Token，并由本机假服务返回拒绝响应；不得撤销或破坏用户真实授权。

## 验收矩阵

### 自动化与制品

- 完整运行 typecheck、单元测试、集成测试、构建和 `npm pack --dry-run`。
- 检查制品仅包含必需运行时、CLI、Manifest、UI、Skill 与文档；不得包含源码、测试、依赖目录、临时状态或凭证。
- 隔离安装后验证插件 loaded/enabled/activated、diagnostics 为零、`pan_sync_upload` Tool、`pan-sync` CLI、`pan-sync-upload` Skill、状态页、配置页面和插件服务均已注册。
- 验证配置页面仅 loopback 可达、一次性授权正确、页面安全头、保存/清除、重载、超时关闭和页面离开时的敏感字段清理。
- 使用本机假 OpenList/阿里云服务验证网络失败、超时、`5xx`、授权拒绝、Token 轮换、并发刷新、重启后的冷却持久化和上传错误映射。
- 运行泄漏测试并扫描制品及净化后的输出，不得出现 Token、一次性密钥、完整配置 URL、临时根路径或测试 canary。

### 当前 OpenClaw 实例

- 安装与隔离环境相同的 `.tgz` 并启用插件。
- 重启网关后验证健康、版本一致、插件运行时注册、CLI、Skill、Tool 与状态页。
- 配置前验证 `unconfigured` 和安全配置指引。
- 配置后验证 `ready`，普通状态页与日志不得显示凭证或完整授权/刷新 URL。

### 真实 OpenList 与阿里云盘

- 用户通过默认中国区 OpenList 授权页完成阿里云盘扫码，并仅把 Refresh Token 粘贴到本机配置页。
- 首次保存成功完成真实 Token 交换并进入 `ready`。
- 上传唯一命名的小文件、含中文和英文字符的文件、同名文件以及超过 40 MiB 的分片文件。
- 使用一组有效与无效本地路径验证多文件部分结果；有效项成功、无效项明确失败，且不重复上传已成功项。
- 通过真实 OpenClaw 对话验证明确的中文与英文上传意图触发 Tool；只讨论网盘用途的消息不得触发上传。
- 重启网关后再次上传唯一命名的小文件，验证凭证持久化与运行时恢复。
- 不强制真实 Access Token 过期。自动刷新分支由隔离确定性测试证明；真实首次配置证明 OpenList Token 交换链路可用。

## 人工操作点

仅在以下环节请求用户操作，并且每次只给出当前一步：

1. 打开本机一次性配置 URL。
2. 在 OpenList 页面选择阿里云盘扫码登录。
3. 将生成的 Refresh Token 粘贴到本机配置页并保存。
4. 必要时登录或重新授权 OpenClaw Dashboard。
5. 遇到真实账号风控、验证码或设备确认时决定是否继续。
